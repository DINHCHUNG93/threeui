# Asset boundary

This repository does not redistribute catalog thumbnails, preview videos, fonts, portraits, textures, or other binary scene assets.

The repository-authored `assets/preview.jpg` and `assets/preview.webm` document the open-source interface itself and are included under MIT. They contain only the public interface and remotely displayed preview imagery; they are not source packages for the depicted catalog items.

Catalog media is displayed from the verified live deployment at `https://threeui.netlify.app` and remains outside this repository and its MIT license. Pro media is provided for preview only. The external media URLs do not grant rights to copy, redistribute, or modify those files.

Community source is included only when the export audit finds no bundled binary assets and no runtime URL outside W3 namespaces, Google Fonts, and pinned Three.js modules. Resources that need asset or third-party license review are omitted by default.
